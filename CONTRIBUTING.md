# Как вносить изменения

Короткие правила для всех, кто правит фронтенд: людей и ИИ-агентов. Запуск и команды описаны в
[README.md](README.md), устройство системы — в [docs/PROJECT_REPORT.md](docs/PROJECT_REPORT.md).

## Порядок работы

1. Ветка от свежего `main`: `feature/<что>`, `fix/<что>` или `chore/<что>`. В `main` напрямую не пушим.
2. Перед PR выполните и добейтесь зелёного результата: `pnpm typecheck`, `pnpm lint` (0 ошибок),
   `pnpm test`, `pnpm build`. То же самое запускает CI.
3. Откройте PR в `main`. Для влития нужны зелёный CI и одно одобрение.
4. Меняете то, что видно на экране, — посмотрите это глазами в светлой и тёмной теме и на ширине
   375 px, а не только прогоните тесты.

## Устройство кода (Feature-Sliced Design)

Слои сверху вниз: `app` → `pages` → `widgets` → `features` → `entities` → `shared`. Слой может
импортировать только нижележащие. Для `shared` это проверяет ESLint (единственное записанное
исключение — `shared/hooks/useTheme.ts`).

| Куда | Что кладём |
|------|-----------|
| `shared/lib/air-quality/` | шкалы и AQI: чистый модуль без React, i18n и импортов вверх (его берёт карта) |
| `entities/weather/` | типы, маппер, запросы, пороги, расчёт средних по пыли |
| `widgets/` | крупные блоки экрана (карточки, графики, шапка) |
| `features/` | отдельные действия пользователя (выбор диапазона, экспорт) |
| `components/ui/` | примитивы shadcn: их генерирует `pnpm dlx shadcn@latest add <name>` |

Правила, на которые чаще всего натыкаются:

- **Логика — в чистых функциях с тестами** (`*.test.ts` рядом с кодом), компонент только показывает
  результат. Тесты запускаются в Node, без DOM.
- **Тексты — только через i18n**: ключи в `src/assets/locales/{ru,uz,en}/common.json`, новый ключ
  добавляется во все три языка (тест на соответствие это проверяет).
- **Цвета и пороги — в одном месте**: зоны нормы в `shared/lib/weather-ranges.ts`, категории пыли в
  `shared/lib/air-quality/`, цвета категорий — переменные `--aqi-*` в `globals.css`.
- **Tailwind v4**: настройки в `src/app/styles/globals.css` (`@theme`), файла `tailwind.config.ts` нет.
  Класс не должен собираться из кусков строк (`` `bg-${x}` ``) — Tailwind его не увидит.
- Менеджер пакетов — **pnpm**; `npm install` не запускать.
- Датчик, которого нет на станции, — это `null` и явная надпись, а не `0`.

## Для ИИ-агентов

Те же правила. Дополнительно: сначала прочитайте затронутые файлы и тесты рядом, не добавляйте
зависимости без необходимости, не переписывайте соседний код «заодно», и каждое утверждение «готово»
подтверждайте выводом команд из пункта 2.
