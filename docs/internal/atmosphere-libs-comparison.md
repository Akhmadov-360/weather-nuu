# Сравнение: наш движок «Атмосферы» и готовые пакеты (эксперимент, 19.11.2026)

Ветка `experiment/atmosphere-libs` (не для слияния). Режим только для разработки: `?engine=lib` рисует
падающие слои пакетами `falling-leaves` 0.1.0 (осень, весна с SVG-лепестками), `react-snowfall` 2.4.0
(зима) и `react-rainfall` 0.3.7 (дождь, холст). Без параметра работает наш движок с «естественным
падением» (ветка `feature/natural-fall`). Слой на пакетах не умеет: посадку на карточки, «душ» из шапки,
небо, гирлянды.

## Замеры

Окно браузера в среде разработки, по 6 секунд на сценарий, один прогон: время JS в кадре (мс, сумма
обратных вызовов `requestAnimationFrame`), без учёта растеризации. Во всех случаях 60 FPS, p95 кадра
16,8–16,9 мс, долгих задач 0.

| Сценарий | Наш движок | Пакеты |
|----------|-----------|--------|
| Осень (листья) | 0,52 | 0,35 |
| Весна (лепестки) | 0,62 | 0,73 |
| Зима (снег) | 0,45 | **1,15** |
| Дождь | 0,38 | 0,24 (но дождь редкий, без настройки) |

Вес в сборке (gzip): наш `AtmosphereStage` 6,9 КБ; `LibStage` 17,0 КБ + 3,5 КБ CSS.
Холстов: у нашего движка два (падающие частицы в окне и «декор» в документе), у пакетов один на каждый
слой.

## Что видно глазами

* Пакеты рисуют **поверх карточек и текста** (частицы пересекают карточку); у нашего движка частицы
  не заходят в тело карточки и садятся на её верхнюю грань.
* Листья пакета выразительнее вблизи (кленовый лист, разные цвета); наши проще.
* Снег пакета гуще и вытянут штрихами при вращении; наш мягкий, с тремя слоями глубины.
* Лепестки на SVG получились бледными (градиент в нашем SVG до белого); настраивается.
* Дождь пакета в базовой настройке редкий; у него есть профили, удары капель, облака, молнии (не включали).

## Вывод

По скорости разницы нет, кроме снега (пакет в 2,5 раза дороже по JS). По возможностям пакеты проигрывают:
нет посадки на карточки и «душа» шапки, частицы закрывают текст, всё вместе в три раза тяжелее в сборке.
Выиграть могут только внешний вид листьев и готовые профили дождя. Решение по умолчанию: оставить наш
движок; при желании перенять у пакетов формы листьев (клён, гинкго) и настройки дождя.
