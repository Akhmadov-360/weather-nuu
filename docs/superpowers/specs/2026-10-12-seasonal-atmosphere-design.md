# Сезонная тема «Атмосфера»: дизайн

Дата: 2026-10-12. Статус: на утверждении. Автор решений: Ахмадов А. (согласовано по частям 1–5 в чате).

## 1. Цель и границы

Дашборд ощущается живым и привязанным к месту и времени: сезон, праздники и реальная погода за окном
меняют оформление, не мешая данным. Цифры, статусы и графики остаются главными.

Входит:

* фоновая сцена на весь дашборд («небо» сверху и частицы, садящиеся на верхние грани карточек);
* сезонная палитра и оттенок шапки (4 сезона);
* реальная погода Open-Meteo поверх сезона (только страница «Улица»);
* праздничные события: Навруз, День независимости, Новый год (с гирляндами), День конституции,
  День учителей; конфетти и закрываемое приветствие;
* три уровня: «Полный», «Спокойный», «Выкл», автоограничение на слабых устройствах, страж FPS;
* две правки интерфейса из того же запроса: вкладки датчиков больше не перетаскиваются, нативная
  полоса прокрутки оформлена в стиле дашборда.

Не входит: торнадо и радарная картина, пыльные бури (нужен отдельный источник), анимированные
иллюстрации в Rive или Lottie (нет дизайнера), день рождения университета (дата не подтверждена).

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Размах | Фон на всю страницу, сезонная палитра и шапка, события |
| Источник сцены | Календарь (сезон, события) + Open-Meteo (осадки, облачность, ветер) + наша температура на «Улице» |
| Управление | Три уровня «Полный / Спокойный / Выкл», выбор пользователя сильнее автоматики |
| Движок | Гибрид: свой canvas-движок, `canvas-confetti` (лениво), шейдер на `ogl` для «дождя на стекле» (лениво, только «Полный» на десктопе) |
| Страница «Аудитория» | Только сезон и события, без реальной погоды |
| Место сцены | Небо сверху, частицы по всему дашборду, осадки садятся на верхние грани карточек |
| События | Навруз, День независимости (1 сентября), Новый год + гирлянды, День конституции (8 декабря), День учителей (1 октября) |

Не берём: tsParticles (тяжелее, труднее подчинить контролю нагрузки), Rive/Lottie, RainyDay.js.

## 3. Архитектура

```
entities/atmosphere/
  model/calendar.ts        сезон и событие по дате (часовой пояс станции)
  model/scene.ts           сезон + события + погода + температура -> описание сцены
  model/weather-code.ts    коды WMO Open-Meteo -> условие и приоритет
  model/tier.ts            сигналы устройства + выбор пользователя -> допустимый уровень
  model/fps-governor.ts    понижение уровня по замеру кадров (чистая функция + тонкий хук)
  api/open-meteo.ts        запрос и кэш (react-query, 15 мин), любая ошибка -> «без погоды»
shared/ui/atmosphere/
  AtmosphereStage.tsx      один fixed <canvas>, лениво подгружаемый чанк
  engine/                  цикл, поверхности, слои: snow, rain, hail, leaves, petals, motes, fog, lights
  confetti.ts              ленивый вызов canvas-confetti
  glass-shader.tsx         ленивый ogl-шейдер (десктоп, «Полный»)
features/atmosphere-settings/
  ui/AtmosphereControl.tsx переключатель уровней в шапке (RubberSegment)
  model/use-atmosphere-level.ts  выбор пользователя (localStorage), итоговый уровень
app/styles/globals.css     токены сезонов: html[data-season="..."]
```

Правила слоёв FSD сохраняются: `shared` не импортирует из верхних слоёв; `entities/atmosphere` не
зависит от React (кроме хуков в `api` и `fps-governor`); карточки помечаются атрибутом
`data-atmosphere-surface`, самих карточек правка не касается.

### 3.1 Интерфейсы (точные имена)

```ts
type Season = 'winter' | 'spring' | 'summer' | 'autumn';
type EventId = 'navruz' | 'independence' | 'new_year' | 'constitution' | 'teachers';
type Level = 'off' | 'calm' | 'full';

sceneFor(date: Date, tz: string): { season: Season; event: EventId | null }

type Condition =
  | 'clear' | 'clouds' | 'fog' | 'drizzle' | 'rain' | 'shower' | 'sleet'
  | 'snow' | 'blizzard' | 'hail' | 'thunder';
type Weather = { condition: Condition; temp: number /*°C, temperature_2m*/; intensity: number /*0..1*/; cloud: number /*0..1*/;
                 windX: number /*px/s, знак = направление*/; isDay: boolean };

describeScene(input: { date: Date; source: 'room' | 'street'; weather: Weather | null;
                       streetTemp: number | null /* датчик станции; null, если молчит или устарел */ }): AtmosphereScene

// Температура для условий жара (≥ 29 °C) и мороз (≤ −5 °C), и для выбора снег/дождь:
// 1) показание датчика «Улицы», пока оно свежее (уровень связи не «архив»);
// 2) иначе `weather.temp` (temperature_2m Open-Meteo);
// 3) иначе температурные эффекты не включаются. Эффект не пропадает, если датчик замолчал.
effectiveTemperature(streetTemp: number | null, weather: Weather | null): number | null
// AtmosphereScene: { season, event, layers: LayerSpec[], tint: { from, to }, lights: boolean, greeting: EventId | null }

deviceCap(signals: DeviceSignals): Level          // потолок по железу и настройкам
effectiveLevel(userChoice: Level | null, cap: Level, governorDrop: boolean): Level
```

## 4. Календарь событий

Окна задаются в часовом поясе станции (Asia/Tashkent), включительно.

| Событие | Окно | Сцена | Конфетти |
|---|---|---|---|
| Навруз | 20–23 марта | зелёно-золотая гамма, лепестки | да |
| День независимости | 31 августа – 1 сентября | сине-бело-зелёный (цвета флага) | да |
| День учителей | 1 октября | тёплое приветствие, листья | нет |
| День конституции | 7–8 декабря | сдержанный праздничный оттенок | нет |
| Новый год | 25 декабря – 7 января | густой снег, гирлянды вдоль верхних граней, мерцание | да |

Сезоны: зима 1 декабря – 28(29) февраля, весна 1 марта – 31 мая, лето 1 июня – 31 августа, осень
1 сентября – 30 ноября. Событие накладывается сверху и не отменяет погоду.

## 5. Сезонная палитра

Базовая палитра (индиго и песок) не меняется. `html[data-season]` подменяет `--season-accent`,
`--season-sky-from`, `--season-sky-to`, `--season-header-tint` для светлой и тёмной темы.
Статусные цвета и цвета серий графиков не трогаются (проверены на контраст и дальтонизм).
Тест контраста: текст на небе и в шапке не ниже 4,5:1 в каждом сезоне и обеих темах.

| Сезон | Акцент | Сцена по умолчанию |
|---|---|---|
| Зима | холодный голубой | редкий мягкий снег |
| Весна | свежий зелёный с лёгким розовым | лепестки по ветру |
| Лето | тёплый песочно-янтарный | пылинки в свете, дрожание воздуха от 29 °C |
| Осень | охра и терракота | падающие листья чинары |

## 6. Погода (только «Улица»)

Источник: `https://api.open-meteo.com/v1/forecast?latitude=41.343&longitude=69.205&current=weather_code,temperature_2m,precipitation,cloud_cover,wind_speed_10m,wind_direction_10m,is_day&timezone=Asia/Tashkent`.
Ключ не нужен, CSP на сервере нет. Кэш 15 минут; при ошибке или отсутствии сети сцена строится без
погоды (только сезон), интерфейс не ломается.

Соответствие кодов WMO: 0 ясно; 1–3 облачность; 45, 48 туман; 51–57 морось; 61–67 дождь;
71–77 снег; 80–82 ливень; 85–86 снегопад; 95 гроза; 96, 99 гроза с градом. Мокрый снег и
ледяной дождь определяются кодами 56, 57, 66, 67 и температурой датчика около нуля.

| Условие | Сцена |
|---|---|
| Ясно | днём блики и лучи, ночью редкие звёзды |
| Облачность | медленные облака, затемнение неба по `cloud` |
| Туман | дымка вдоль нижних краёв карточек |
| Морось, дождь, ливень | капли, всплески и ряби на верхних гранях, густота по `intensity` |
| Мокрый снег | смесь капель и хлопьев, шапка быстро тает |
| Снег, метель | хлопья садятся на грани, ветер наклоняет траектории |
| Град | отскакивающие горошины |
| Гроза | вспышки неба плюс дождь |
| Сильный ветер | наклон и порывы всех частиц |
| Жара от 29 °C | дрожание воздуха |
| Мороз от −5 °C и ниже | изморозь на гранях |

Приоритет: гроза, град, метель и снег, мокрый снег, ливень и дождь, морось, туман, облачность, ясно.
Температура уточняет осадок (снег против дождя) и включает жару и мороз; берётся с нашего датчика, а при его молчании из `temperature_2m` Open-Meteo (`effectiveTemperature`, см. 3.1).

## 7. Осадки «садятся» на карточки

* Поверхность: верхняя грань элемента с `data-atmosphere-surface` (координаты в окне; обновляются
  при прокрутке и изменении размера, не чаще раза за кадр, через `ResizeObserver` и `scroll`).
* Снег: хлопья, пересёкшие грань, остаются на ней; на грани растёт «шапка» до 5 px, тает за
  ~60 секунд после окончания снега.
* Дождь: на грани всплеск из 2–3 микрочастиц и кольцо ряби.
* Лепестки (весна): садятся как снег, не копятся. Листья (осень): лежат на грани несколько секунд и
  скатываются.
* Частицы никогда не рисуются поверх содержимого карточки: они останавливаются на грани. Над
  текстом летят только частицы в зазорах и над шапкой (малые, прозрачность не выше 0,35).
* Гирлянды (Новый год): шнур по верхним граням, огоньки мерцают; в уровне «Спокойный» статичны.
* На телефоне зазоры узкие, осадки в основном оседают на верхних карточках; сцена проще.

## 8. Уровни, устройство, защита от просадок

* **Выкл:** нет сцены и сезонной палитры; приветствия скрыты.
* **Спокойный:** сезонная палитра, статичное небо и орнамент; без canvas, без анимации,
  тяжёлые чанки не подгружаются; приветствие показывается.
* **Полный:** частицы по данным, конфетти, на десктопе шейдер стекла.

Потолок по устройству (`deviceCap`): `prefers-reduced-motion`, `saveData`, соединение 2g/3g, память
≤2 ГБ или ядер ≤2 дают «Спокойный». Телефон: «Полный», без шейдера, бюджет частиц вдвое меньше.
Бюджет частиц «Полного»: не более 120, DPR не выше 2.

Страж FPS: после старта окна по 2 секунды; два подряд окна хуже ~40 FPS опускают уровень на
сессию на ступень (`sessionStorage`), показывается уведомление «Анимации упрощены для плавности»
с кнопкой «Вернуть». Вверх автоматически не поднимает. При ручном «Полный» страж только
предлагает понизить, не понижает сам.

Выбор пользователя хранится в `localStorage` (`atmosphere-level`); пока не выбран, действует авто.
Переключатель показывает подсказку «Авто: Спокойный (экономия трафика)», если уровень ограничен.
Пауза на скрытой вкладке; `aria-hidden` у сцены; события и частицы не принимают указатель.

## 9. Приветствия событий

Тонкая закрываемая полоса вверху, один раз в сутки на событие (`localStorage`), на «Спокойном» и
«Полном». Тексты (черновик, проверить формулировки):

| Событие | ru | uz | en |
|---|---|---|---|
| Навруз | С праздником Навруз! | Navro‘z bayrami muborak bo‘lsin! | Happy Navruz! |
| Независимость | С Днём независимости! | Mustaqillik bayrami muborak bo‘lsin! | Happy Independence Day! |
| День учителей | С Днём учителей! | Ustoz va murabbiylar kuni muborak bo‘lsin! | Happy Teachers’ Day! |
| Конституция | С Днём Конституции! | Konstitutsiya kuni muborak bo‘lsin! | Happy Constitution Day! |
| Новый год | С Новым годом! | Yangi yilingiz muborak bo‘lsin! | Happy New Year! |

Узбекские тексты проверены носителем: в латинице используется типографский апостроф `‘`
(U+2018: `Navro‘z`, `bo‘lsin`), а не прямой `'`. Тест на строки локали проверяет отсутствие
прямого апострофа в этих ключах.

## 10. Две правки интерфейса

1. **Вкладки датчиков:** `draggable={false}` у `RubberSegment` в `ChartSelector`; прокрутка вбок
   работает на телефоне и планшете. Тап и клавиатура остаются. У ряда периодов перетаскивание
   остаётся (он умещается).
2. **Полоса прокрутки:** нативная полоса под вкладками заменяется тонкой, в токенах дашборда
   (`scrollbar-width: thin; scrollbar-color`), а у вкладок прячется с лёгким затуханием по краям,
   намекающим на продолжение. Стиль действует на все горизонтальные прокрутки.

## 11. Тестирование

* Чистые функции с тестами: `sceneFor` (границы окон, високосный год), `describeScene`
  (приоритеты, «Аудитория» без погоды), `effectiveTemperature` (датчик свежий, датчик молчит, оба недоступны), `weather-code`, `deviceCap`, `effectiveLevel`, физика
  поверхностей (посадка частицы, рост и таяние шапки), выбор сезона и палитры.
* Контраст палитры сезонов: тест на токены, как у существующей палитры.
* Ручная проверка: каждый сезон и событие через dev-параметры `?season=` и `?event=` и `?weather=`
  (только в режиме разработки), светлая и тёмная тема, 320–1440 px, уровни «Полный / Спокойный /
  Выкл», `prefers-reduced-motion`, скрытая вкладка, имитация слабого устройства.
* Нагрузка: замер FPS и размера чанков; основной бандл не растёт (сцена и confetti, ogl подгружаются
  лениво только на «Полном»).

## 12. Риски и открытые вопросы

* Open-Meteo недоступен: сцена без погоды (ожидаемо). Лимиты бесплатного API достаточны (один
  запрос на посетителя в 15 минут), при росте трафика кэшировать на нашем сервере.
* Много верхних граней и частиц: пересчёт граней ограничен, бюджет частиц и страж FPS страхуют.
* Контраст тёмной темы с зимним небом: проверяется тестом.
* Закрыто 12.10.2026: окно Навруза 20–23 марта подтверждено; формулировки приветствий уточнены;
  отдельный праздник «День знаний» не делаем, он объединён с Днём независимости (1 сентября), чтобы не
  перегружать интерфейс двумя баннерами и разными конфетти.
