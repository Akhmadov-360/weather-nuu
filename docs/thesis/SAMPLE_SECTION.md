## 2.3 Расчёт индекса качества воздуха (AQI)

### 2.3.1 Постановка задачи

Датчик пыли измеряет массовую концентрацию частиц PM2.5 в микрограммах на кубический метр
(мкг/м³). Для человека число «35,5 мкг/м³» ничего не говорит, поэтому его переводят в индекс
качества воздуха (Air Quality Index, AQI): число от 0 до 500 и одну из шести категорий («хорошо»,
«умеренно», …, «опасно»). В работе используется методика Агентства по охране окружающей среды США
(US EPA) в редакции 2024 года: она открыта, широко известна и согласована с научным руководителем
(раздел 1.4).

Требуется по концентрации `C` получить индекс `I` и категорию так, чтобы:

1. результат совпадал с официальной таблицей EPA на любых входных значениях;
2. отсутствие показания (`null`) никогда не превращалось в «0» и, значит, в «чистый воздух»;
3. результат не зависел от погрешностей вычислений с плавающей точкой на границах категорий.

### 2.3.2 Метод

Шкала задана таблицей диапазонов (таблица 2.1): каждой категории соответствует интервал
концентраций `[BP_Lo; BP_Hi]` и интервал индекса `[I_Lo; I_Hi]`. Внутри категории индекс
вычисляется линейной интерполяцией:

```
         I_Hi − I_Lo
I  =  ───────────────── · (C − BP_Lo) + I_Lo                       (2.1)
         BP_Hi − BP_Lo
```

где `C` — концентрация, усечённая до разряда стандарта; `BP_Lo`, `BP_Hi` — границы диапазона,
в который попала `C`; `I_Lo`, `I_Hi` — границы соответствующего диапазона индекса. Результат
округляется до целого.

Таблица 2.1 — Границы категорий для PM2.5 (US EPA, редакция 2024, 24-часовое среднее)

| Категория | PM2.5, мкг/м³ | AQI |
|-----------|---------------|-----|
| Хорошо | 0,0 – 9,0 | 0 – 50 |
| Умеренно | 9,1 – 35,4 | 51 – 100 |
| Вредно для чувствительных групп | 35,5 – 55,4 | 101 – 150 |
| Вредно | 55,5 – 125,4 | 151 – 200 |
| Очень вредно | 125,5 – 225,4 | 201 – 300 |
| Опасно | 225,5 – 325,4 | 301 – 500 |

**Усечение, а не округление.** По правилам EPA концентрация PM2.5 перед поиском диапазона
отбрасывает все знаки после первого десятичного (для PM10: после запятой), то есть берётся целая
часть `⌊C · 10⌋ / 10`. Обычное округление дало бы неверную категорию: значение 35,46 при
округлении стало бы 35,5 («вредно для чувствительных групп»), а по методике это 35,4 («умеренно»).

**Период усреднения.** Официальный AQI считается по 24-часовому среднему. Чтобы показывать «сейчас»,
система считает ещё и 10-минутное среднее, но подписывает, что это не официальный индекс (рисунок
2.1). Среднее принимается, только если данных достаточно: для 10 минут не менее 60 показаний из
ожидаемых 120 (плата шлёт точку раз в 5 секунд), для суток не менее 75 % покрытия.

### 2.3.3 Числовой пример

Пусть среднее за сутки `C = 22,25` мкг/м³.

1. Усечение: `⌊22,25 · 10⌋ / 10 = 22,2`.
2. Диапазон: `22,2` попадает в «умеренно» (`BP_Lo = 9,1`, `BP_Hi = 35,4`, `I_Lo = 51`, `I_Hi = 100`).
3. По формуле (2.1): `I = (100 − 51) / (35,4 − 9,1) · (22,2 − 9,1) + 51 = 1,8631 · 13,1 + 51 = 75,4`.
4. Округление: `I = 75`, категория «умеренно».

### 2.3.4 Реализация

Стандарт описан данными (таблицей), а не кодом; расчёт общий для любой таблицы. Ниже ключевая часть
(полный код в приложении А).

```ts
// Усечение, а не округление. Эпсилон гасит двоичную ошибку: сумма десяти раз по 0,1 равна 0,9999999999999999,
// и без него она усеклась бы до 0,9.
function truncate(value: number, decimals: number): number {
  const factor = 10 ** decimals;
  return Math.floor(value * factor + 1e-9) / factor;
}

export function aqi(standard: Standard, pollutant: Pollutant, value: number | null | undefined): number | null {
  if (!isUsable(value)) return null;                 // null, NaN, отрицательные: «нет показания»
  const rows = standard.breakpoints[pollutant];
  const truncated = truncate(value, standard.decimals[pollutant]);
  if (truncated > rows[rows.length - 1]!.cHigh) return 500;
  const row = findRow(rows, truncated);
  const slope = (row.aqiHigh - row.aqiLow) / (row.cHigh - row.cLow);   // формула (2.1)
  return Math.round(slope * (truncated - row.cLow) + row.aqiLow);
}
```

Региональная норма добавляется отдельным файлом с такой же таблицей и записью в реестре, без правки
расчёта. Это важно, потому что нормы Узбекистана подтвердить не удалось (раздел 1.4).

### 2.3.5 Проверка

Корректность проверена тремя способами (подробнее в главе 4):

* автоматические тесты на каждой границе категорий и на значениях «чуть выше границы»;
* перебор всех значений с шагом 0,1 мкг/м³ от 0 до 330: категория совпадает с независимым
  эталоном на целых числах, индекс не убывает с ростом концентрации;
* общий файл из 109 эталонных значений, который проверяют одинаково серверная и клиентская
  реализации: если одна из них изменится, тесты другой упадут.

### 2.3.6 Ограничения

* 10-минутное среднее показывает состояние «сейчас», но не равно официальному суточному индексу.
* Датчик Plantower завышает показания при высокой влажности; поправка не вводилась (раздел 4.4).
* Индекс по PM2.5 не учитывает газы; показания газовых датчиков MQ даются как оценки.

### 2.3.7 Вывод

Расчёт AQI реализован по открытой методике EPA с проверкой на границах и защитой от потери
показаний; стандарт описан данными, что позволяет подключить региональную норму без изменения
алгоритма.
