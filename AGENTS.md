# Инструкции для ИИ-агентов

Все правила работы с репозиторием — в [CONTRIBUTING.md](CONTRIBUTING.md); запуск и команды — в
[README.md](README.md). Минимум, который нельзя пропускать: `pnpm typecheck`, `pnpm lint`,

не импортирует из верхних слоёв.
